# راهنمای ساخت EXE — Glass Translator 0.2.6

این راهنما مربوط به سورس کامل داخل همین پوشه است؛ از فایل‌های پچ نسخه‌های دیگر استفاده نکن.

## پیش‌نیاز

- ویندوز 10/11 نسخهٔ 64 بیتی
- Python 3.11 x64 و Python Launcher
- اجرای موفق `setup_windows.bat`
- پیشنهاد می‌شود پیش از ساخت، `run_windows.bat` را اجرا کرده و مطمئن شوی برنامه باز می‌شود.

## ساخت

1. برنامه را ببند.
2. مطمئن شو پوشهٔ `.venv` در ریشهٔ سورس موجود است.
3. `build_windows_exe.bat` را اجرا کن.
4. این اسکریپت ابتدا کتابخانه‌های موردنیاز را بررسی می‌کند، سپس تست‌های خودکار را اجرا می‌کند، PyInstaller را در `.venv` نصب/به‌روزرسانی می‌کند و ساخت `onedir` را انجام می‌دهد.
5. اگر موفق باشد، پیام `BUILD SUCCESSFUL` نمایش داده می‌شود.

## خروجی

- اجرایی: `dist\GlassTranslator\GlassTranslator.exe`
- پوشهٔ کامل قابل انتقال: `dist\GlassTranslator\`
- ZIP پوشهٔ خروجی: `GlassTranslator_Windows_x64.zip`

کل پوشهٔ `dist\GlassTranslator` را نگه دار؛ فایل EXE را به‌تنهایی جابه‌جا نکن. حالت `onedir` به‌دلیل استفادهٔ برنامه از PySide6، PyTorch و EasyOCR از یک فایل تک‌تایی مطمئن‌تر است.

## مدل‌ها و داده‌های خارج از EXE

- مدل Argos در `%APPDATA%\GlassTranslator\argos-packages` ذخیره می‌شود.
- تنظیمات و تاریخچه نیز زیر `%APPDATA%\GlassTranslator` قرار دارند.
- مدل‌های OCR از طریق EasyOCR مدیریت می‌شوند و ممکن است در نخستین اجرا به دانلود نیاز داشته باشند.
- Local AI به اجرای LM Studio وابسته است.
- Online به دسترسی اینترنت وابسته است.

در همان رایانه و همان حساب ویندوز، ساخت EXE از مسیر پایدار AppData استفاده می‌کند؛ بنابراین مدل Argos نصب‌شده معمولاً بدون نصب دوباره قابل استفاده است. در رایانه یا حساب کاربری دیگر، باید مدل‌های مربوطه را آنجا نیز نصب کنی.

## اگر ساخت شکست خورد

1. متن کامل پنجرهٔ BAT را ذخیره کن.
2. پوشهٔ `.venv` و مدل Argos را حذف نکن.
3. با اجرای `test_windows.bat` مشخص کن تست‌ها موفق‌اند یا نه.
4. اگر خطا به PyInstaller مربوط است، نام مرحله و آخرین خطای کامل را بررسی کن.

توجه: ساخت واقعی EXE فقط پس از اجرای موفق اسکریپت روی ویندوز تأیید می‌شود؛ اجرای تست‌های سورس به‌تنهایی به معنی ساخته‌شدن EXE نیست.
