# فونت ایران‌سنس

برای اینکه برنامه روی رایانه‌هایی که فونت ایران‌سنس نصب نیست هم دقیقاً با همین فونت اجرا شود، فایل فونت دارای مجوز استفاده و توزیع را در همین پوشه قرار بده؛ مثلاً:

- `IRANSans.ttf`
- `IRANSansX-Regular.ttf`
- `IRANSansWeb.ttf`

برنامه فایل‌های TTF/OTF/TTC این پوشه را در زمان اجرا بارگذاری می‌کند و اگر خانواده فونت ایران‌سنس را تشخیص دهد، از آن استفاده خواهد کرد. پوشه `assets` در ساخت EXE بسته‌بندی می‌شود.

خود فونت در این بسته قرار نگرفته است؛ پیش از بازتوزیع یک فایل فونت، مجوز استفاده و توزیع آن را بررسی کن. اگر فونت در پوشه یا ویندوز موجود نباشد، برنامه از فونت فارسی موجود (در اولویت Tahoma) استفاده می‌کند.
