# Glass Translator 0.2.7 — راهنمای کامل فارسی

Glass Translator یک مترجم شناور برای ویندوز است که متن انگلیسی را از محدوده‌ای که با ماوس انتخاب می‌کنی می‌خواند و ترجمهٔ فارسی را در پنل شیشه‌ای نمایش می‌دهد.

این پوشه، **سورس کامل به‌همراه اسکریپت‌های نصب، آزمایش و ساخت EXE** است. این بسته پچ نیست و برای استفاده از آن نباید فایل‌های چند نسخه را با هم ترکیب کنی. نسخهٔ ۰.۲.۷ رابط را به حالت راست‌به‌چپ تنظیم می‌کند و از ایران‌سنس در صورت نصب یا قرارگرفتن فایل فونت در `assets/fonts` استفاده می‌کند.

## نصب سریع

1. ZIP را در یک پوشهٔ مستقل استخراج کن.
2. Python 3.11 x64 را نصب کن؛ گزینهٔ Python Launcher (`py`) فعال باشد.
3. `setup_windows.bat` را اجرا کن و تا پایان نصب صبر کن.
4. `install_offline_model.bat` را اجرا کن تا مدل انگلیسی‌به‌فارسی Argos دریافت و آزمایش شود.
5. `check_offline_model.bat` را اجرا کن و مطمئن شو نتیجه می‌گوید مدل آفلاین آماده است.
6. `run_windows.bat` را اجرا کن.
7. بعد از اینکه برنامه را آزمایش کردی، برای ساخت EXE، `build_windows_exe.bat` را اجرا کن.

راهنمای گام‌به‌گام با جزئیات بیشتر در `START_HERE_FA.md` قرار دارد.

## قابلیت‌ها

- رابط فارسی راست‌به‌چپ و راست‌چین برای برچسب‌ها و فیلدهای فارسی
- پشتیبانی از IRANSans / IRANSansX / IRANSansWeb؛ فیلدهای انگلیسی و URL چپ‌چین باقی می‌مانند
- نوار ابزار شناور و آیکونی؛ حالت روشن/تاریک
- انتخاب یک محدودهٔ صفحه با ماوس و پوشش نیمه‌شفاف
- OCR متن انگلیسی با EasyOCR
- پنل ترجمهٔ شیشه‌ای با متن انگلیسی و فارسی و کنترل مستقل بخش‌ها
- شش تم رابط کاربری
- تاریخچه با جست‌وجو، کپی، نشان‌کردن و خروجی TXT/CSV/JSON
- واژه‌نامه برای نام‌ها و اصطلاحات
- نگهداری اختیاری تاریخچه بین اجراها
- cache ترجمه‌ها برای کم‌کردن درخواست‌های تکراری
- موتور Online با Google Translate (رابط وب غیررسمی) یا LibreTranslate
- موتور Local AI با LM Studio و API سازگار با OpenAI
- موتور Offline با Argos Translate انگلیسی به فارسی
- آزمایش اتصال موتور انتخاب‌شده و پیام خطای فارسی
- میان‌برهای سراسری: `Ctrl+Shift+T` برای پنل، `Ctrl+Shift+R` برای OCR و `Ctrl+Shift+H` برای تاریخچه

## جهت رابط و فونت ایران‌سنس

جهت کلی رابط راست‌به‌چپ است و برچسب‌ها و ورودی‌های فارسی راست‌چین‌اند. متن تشخیص‌داده‌شدهٔ انگلیسی، نشانی‌های API، شناسهٔ مدل و فیلدهای انگلیسی برای خوانایی چپ‌چین باقی می‌مانند. برنامه ابتدا خانواده‌های IranSans / IranSansX / IranSansWeb را جست‌وجو می‌کند. برای اینکه فونت در EXE روی رایانه‌ای بدون فونت نصب‌شده هم یکسان باشد، فایل دارای مجوز بازتوزیع را داخل `assets/fonts` قرار بده و سپس دوباره EXE را بساز. فایل فونت به‌دلیل مجوز بازتوزیع در این بسته قرار نگرفته است؛ در نبود آن، Tahoma ترجیح داده می‌شود.

## سه موتور ترجمه

### Online

در تنظیمات ارائه‌دهندهٔ آنلاین را انتخاب کن. Google Translate در این پروژه از رابط وب غیررسمی استفاده می‌کند؛ احتمال محدودیت نرخ درخواست یا تغییرات سرویس وجود دارد. در صورت خطای HTTP 429، ممکن است لازم باشد مدتی صبر کنی یا ارائه‌دهندهٔ دیگری را انتخاب کنی. LibreTranslate به نشانی API سازگار و گاهی کلید API نیاز دارد. در صورت نیاز پروکسی HTTP/HTTPS را در تنظیمات وارد کن.

### Local AI

LM Studio را باز کن، مدل گفت‌وگومحور را Load کن و Local Server را روشن کن. نشانی پیش‌فرض `http://127.0.0.1:1234/v1` است. برنامه از API محلی استفاده می‌کند. زمان ترجمه به مدل انتخاب‌شده و تنظیمات آن بستگی دارد.

### Offline

`install_offline_model.bat` مدل انگلیسی به فارسی Argos را نصب می‌کند. دریافت اولیهٔ مدل به اینترنت نیاز دارد؛ پس از نصب موفق، ترجمهٔ متن بدون اینترنت و بدون LM Studio انجام می‌شود. مدل Argos در `%APPDATA%\GlassTranslator\argos-packages` نگهداری می‌شود، نه داخل `.venv`.

## ساخت EXE

روی ویندوز ۱۰/۱۱ نسخهٔ ۶۴ بیتی، فایل `build_windows_exe.bat` را اجرا کن. اگر `.venv` وجود نداشته باشد، اسکریپت با Python 3.11 آن را می‌سازد و سپس وابستگی‌ها را نصب/بررسی می‌کند. در صورت پیدا شدن مدل Argos و مدل‌های EasyOCR روی همان رایانه، آن‌ها را هم در خروجی بسته‌بندی می‌کند. خروجی PyInstaller:

`dist\GlassTranslator\GlassTranslator.exe`

اسکریپت همچنین `GlassTranslator_Windows_x64_v0.2.7.zip` می‌سازد. اگر Inno Setup 6 نصب باشد، فایل `installer_output\GlassTranslator_Setup_x64_v0.2.7.exe` را نیز با حذف‌نصب استاندارد می‌سازد. کل پوشهٔ `dist\GlassTranslator` را نگه دار و فایل EXE را از وابستگی‌هایش جدا نکن. راهنمای ساخت در `README_BUILD_EXE_FA.md` است.

ساخت EXE باید روی ویندوز و در محیط Python 3.11 پروژه انجام شود. اگر هنگام ساخت مدل Argos و هر دو مدل OCR شناسایی نشوند، برنامه در ساخت هشدار می‌دهد و ممکن است نخستین اجرا به نصب/دریافت مدل نیاز داشته باشد. برای اجرای Portable با تنظیمات و تاریخچهٔ محلی، فایل `run_portable_windows.bat` موجود در پوشهٔ خروجی را اجرا کن.

## تست‌ها

تست خودکار را با `test_windows.bat` یا با دستور زیر از پوشهٔ پروژه اجرا کن:

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

تست‌های خودکار، بخشی از منطق ترجمه و مدیریت خطا را با پاسخ‌های شبیه‌سازی‌شده بررسی می‌کنند. اتصال زنده به Google/LibreTranslate، LM Studio و نصب واقعی Argos باید روی دستگاه هدف آزمایش شود.

## نیازمندی‌ها و نکات

- Windows 10/11 x64
- Python 3.11 x64 برای نصب سورس و ساخت EXE
- اینترنت برای نصب اولیهٔ کتابخانه‌ها، دریافت مدل Argos و در صورت نیاز مدل‌های EasyOCR
- LM Studio برای موتور Local AI
- بازی‌ها در حالت Borderless Windowed معمولاً برای Overlay مناسب‌تر از Exclusive Fullscreen هستند؛ سازگاری با همهٔ بازی‌ها تضمین‌شده نیست.

## ساختار فایل‌ها

| فایل | کاربرد |
|---|---|
| `main.py` | شروع برنامه و اتصال اجزا |
| `ui.py` | رابط کاربری، نوار ابزار، پنل، تنظیمات، تاریخچه |
| `translator.py` | موتورهای Online/Local AI/Offline |
| `ocr_worker.py` | خواندن متن از محدودهٔ انتخابی |
| `history.py` | مدیریت تاریخچه |
| `config.py` | تنظیمات و تم‌ها |
| `install_offline_model.py` | دریافت، نصب و تست مدل Argos |
| `check_offline_model.py` | بررسی مسیر مدل و ترجمهٔ آزمایشی |
| `GlassTranslator.spec` | تنظیمات PyInstaller |
| `assets/` | آیکون، فونت اختیاری و منابع بسته‌بندی‌شده |

در حالت معمول تنظیمات و تاریخچه در `%APPDATA%\GlassTranslator` ذخیره می‌شوند. در حالت Portable که با `run_portable_windows.bat` اجرا می‌شود، تنظیمات و تاریخچه در پوشهٔ `data` کنار EXE نگهداری می‌شوند. برای تغییر یا عیب‌یابی، ابتدا گزارش فایل‌های `check_offline_model.bat` و `build_windows_exe.bat` را نگه دار.
